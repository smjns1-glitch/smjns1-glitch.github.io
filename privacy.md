# Privacy Policy - Gmail MCP

Gmail MCP is a personal tool used only by its owner, Rambo Jacob, to access his own Gmail accounts from Claude Desktop on his own computer. It is not offered to the public.

**Data accessed:** Gmail messages, labels and drafts of the signed-in accounts, used only to carry out the owner's own requests.

**Storage:** Sign-in tokens are stored only on the owner's computer. No Gmail data is sent to, stored on, or shared with any server operated by this app.

**Sharing:** Data is not sold, shared, or used for advertising.

**Revoking access:** Access can be removed at any time at https://myaccount.google.com/permissions

**Contact:** Open an issue at https://github.com/smjns1-glitch/smjns1-glitch.github.io/issues
